# ESP8266 & Arduino 電子工作ブログ

ESP8266・Arduinoをはじめとした電子工作の情報を発信するブログ・コンテンツ管理用リポジトリです。
初心者の方でも理解できるように、部品選びから配線、コードの書き方までをやさしく解説することを目指しています。

## プロジェクト概要

- ESP8266・Arduinoを使った電子工作の作例やチュートリアルを記事としてまとめます
- 初心者向けに、専門用語をかみ砕きながら解説します
- 記事内で紹介する部品・工具はAmazonアフィリエイトリンクを前提として掲載します
- 検索流入(SEO)を意識した記事構成・タイトル付けを行います

## 今後作る予定

詳しい進め方は[ROADMAP.md](./ROADMAP.md)、最初の100記事の計画は[CONTENT_PLAN.md](./CONTENT_PLAN.md)を参照してください。

- [ ] ESP8266入門記事(開発環境構築、Lチカ)
- [ ] Arduino入門記事(開発環境構築、Lチカ)
- [ ] センサー活用シリーズ(温湿度・照度・人感センサーなど)
- [ ] Wi-Fi通信を使った作例(IoT実践編)
- [ ] AI×電子工作シリーズ(画像認識・音声認識・生成AI連携など)
- [ ] おすすめ部品・工具のまとめ記事(アフィリエイト導線)
- [ ] トラブルシューティング集
