# quality-development: 重大判断リスト・リスク分類・終了条件・重大度定義

`quality-development/SKILL.md` と `.claude/agents/independent-reviewer.md` の両方から参照される
共通定義。定義を変更する場合はこのファイルのみを更新し、SKILL.md・independent-reviewer.mdには
コピーしない。

## 1. 重大判断リスト(該当時のみユーザーに確認して停止する)

以下のいずれかに該当する場合のみ、作業を止めて `AskUserQuestion` または `EnterPlanMode` で
オーナーに確認する。該当しない判断は、確認なしでそのまま進めてよい(過剰停止を避ける)。

1. 有料API・有料サービスの追加
2. 新規外部サービスの導入
3. APIキーや秘密情報が必要になる変更
4. 破壊的なデータベース変更
5. 大規模なアーキテクチャ変更
6. 本番環境への操作
7. 大量または不可逆な削除
8. 上記に準ずる、後戻りが困難で影響範囲が大きい判断

このリストにない判断(通常のコード修正・記事執筆・部署提案の反映など)は「重大判断」に該当しない。
このリストへの該当がそのまま「5. リスクベースの品質ゲート」のHIGHにあたる。

## 2. Iterative Refinementの終了条件

以下をすべて満たした場合に反復を終了する。

- 重大問題(BLOCKER)が0件
- 必要なテスト・検証(Automated Validation)がPASSしている
- 元のタスクの要件を満たしている
- 自己評価が90点以上(目安。他条件を満たしていれば厳密な必須条件ではない)
- iteration回数が3回以内

3iteration到達後もいずれかの条件を満たさない場合、それ以上の変更は行わず、`BLOCKED`として
未解決事項を残課題(`docs/TODO.md`の`Blocked`)に記録して終了する(無理な追加変更・無限ループを
避ける)。MINORのみを理由に反復を継続しない。

## 3. 重大度(severity)の定義

Independent Reviewerの指摘、および自己評価での問題分類は以下の3段階を使う。`CHECK_RESULT: NG`は
BLOCKERが1件でもある場合、または要件を満たさない場合に付ける。

- **BLOCKER**: 要件を満たさない、事実誤認・創作を含む、安全上の注意(電圧・極性・発熱・ショート等)が
  欠落している、公開/実行してはいけない状態にある、など。1件でもあれば終了条件を満たさない。
- **MAJOR**: 要件は満たすが、初心者の理解を妨げる・SEO/事実性/技術安全の観点で明確な改善余地がある
  など、公開・完了前に直すべき問題。
- **MINOR**: あると良いが必須ではない改善提案。終了条件の判定には数えない。

## 4. 適用対象外(Step 0で除外する作業)

- 質問への回答・調査・説明のみで、新たな成果物を作らないタスク
- 数行程度の自明な修正(typo修正、コメント追加など)
- 既存指示をそのまま実行するだけで、判断の余地がないタスク

## 5. リスクベースの品質ゲート(LOW / MEDIUM / HIGH)

Step 0の「適用対象外」を通過した(=このフローの対象になった)作業を、さらに次の3段階に分類する。
LOWはStep 0より軽いが、フロー自体は適用される点に注意する。

- **LOW**: ドキュメント修正・コメント・typo以上だが小規模な表示変更・軽微な文言修正など。
  Self Evaluationのみで完了してよく、Independent Reviewerの起動は必須としない(呼び出し元の判断で
  省略可)。Task Decomposition(SKILL.md Step 2)は単一Taskのまま省略してよく、State Update
  (SKILL.md Step 9)も`docs/TODO.md`の該当行を1行更新する程度で足りる。
- **MEDIUM**: 通常の機能追加・bug fix・リファクタリング・通常の記事執筆など。Automated Validation +
  Self Evaluation + Independent Reviewを通常どおり実施する(デフォルトの重さ)。
- **HIGH**: 「1. 重大判断リスト」に該当する変更。detailed Plan First + Automated Validation +
  Independent Review + 必要なら追加のセキュリティ観点レビュー + 人間の確認(Plan Firstでの停止)を
  必須とする。
