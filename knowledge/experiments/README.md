# experiments

試したことの記録。結果が良かったものだけでなく、**失敗した実験も残す**(消さない)。

各ファイルには最低限以下を持たせる:

- hypothesis(何を検証したかったか)
- implementation(何をしたか)
- result(何が起きたか)
- evidence(根拠。数値・ログ・スクリーンショット等へのポインタ)
- conclusion(結論)
- next action
