# ideas

まだ採用されていない**非記事**のアイデア置き場(サイト機能・運用改善・ツール・将来のサービス構想など)。

**記事のアイデアはここに置かない。** 記事企画・優先順位の正本は[`CONTENT_PLAN.md`](../../CONTENT_PLAN.md)
であり、`knowledge/ideas/`は記事企画とは別名前空間。

各アイデアファイルには最低限以下を持たせる:

- idea(何をするか)
- problem(何を解決するか)
- target(誰のためか)
- expected value(期待効果)
- assumptions(前提)
- next action(次に何をすべきか)
- status
