## Lチカとは?

「Lチカ」は「LED点滅(LEDをチカチカさせる)」の略で、電子工作でよく使われる俗称です。Arduinoに限らず、マイコンを使った電子工作で最初に取り組む定番の課題として知られています。

第1号記事「[Arduinoとは？電子工作初心者だった僕が最初に選んだ理由と始め方]({{ "/articles/arduino-toha-hajimekata/" | relative_url }})」で紹介した通り、筆者も最初にシリアルモニタへ「Hello World」を表示させたあと、このLチカに取り組みました。この記事では、そのときの実体験をもとに、配線・コード・つまずいたポイントを紹介します。

## 実際の配線とLEDについて

正直なところ、当時どのピンを使ったかは覚えていません。基本的な入出力用のピンを使ったという記憶はありますが、具体的な番号までは未確認です。

### 実体験: 電流制限用の抵抗を使わなかった

ここが今回、特に正直に書いておきたい点です。LEDを保護するために抵抗(目安として1,000Ω程度)を入れる必要があると当時から認識はしていましたが、実際には抵抗を使わずにLEDを直結しました。「LEDが壊れてもいいか」という軽い気持ちで進めた、というのが実際のところです。

> **安全上の注意(抵抗を省略することについて)**
> LEDに抵抗を入れずに直結すると、LEDや接続したピンに流れる電流を制限できません。Arduino公式の仕様(Arduino Uno Rev3、2026年8月確認)では、I/Oピン1本あたりのDC電流は20mA(ミリアンペア)とされています。抵抗なしでLEDを5Vのピンに直結すると、この推奨値を超える電流が流れ、LEDの早期劣化・焼損や、ピンへの負荷につながる可能性があります。実際に短時間で壊れるとは限りませんが、これは「たまたま壊れなかった」だけの可能性がある、推奨されない配線です。これからLチカに取り組む方は、電流制限用の抵抗を必ず入れることをおすすめします。
> (参考: [Arduino UNO Rev3 – Reliable ATmega328P Board with Digital & Analog I/O](https://store-usa.arduino.cc/products/arduino-uno-rev3) 記載の「DC Current per I/O Pin: 20 mA」を2026年8月確認)

### おすすめの配線(抵抗を使う場合)

これから取り組む方には、以下のような配線をおすすめします(ブレッドボード=はんだ付けせずに部品や配線を差し込んで回路を試せる基板、を使う場合を想定しています)。

- Arduinoのデジタル出力ピン(例: 2番ピン。お使いのコードに合わせて変更してください) → 抵抗 → LEDの長い脚(アノード、+側)
- LEDの短い脚(カソード、-側) → Arduinoの GND(グラウンド)

これはArduinoのピン→抵抗→LED→GNDと1本の輪(直列回路)でつながっていれば電気的に成立する回路です。上の配線例では抵抗をピン側に置いていますが、LED側(GND寄り)に置いても、直列につながってさえいれば電気的な働きは同じです。

ブレッドボードを使う場合は、部品の足やジャンパー線を、同じ「導通列」(内部で電気的につながっている一列)に挿す必要があります。列がずれていると、見た目は近くても電気的にはつながっていないため、点灯しません。お使いのブレッドボードの導通の向き(縦か横か)は製品によって異なるため、パッケージの説明もあわせてご確認ください。

抵抗の値は使用するLEDによって変わりますが、初心者向けの一般的な目安としては220Ω〜1kΩ程度がよく使われます。正確に計算したい場合は「(電源電圧 - LEDの順方向電圧) ÷ 流したい電流」で求められますが、LEDの正確な定格(順方向電圧・許容電流)はデータシートやパッケージの表示を確認してください。今の自分なら、配線前に使用するLEDがどの程度の電流まで耐えられるのかを事前に調べておくと思います。

LEDには極性(向き)があり、長い脚(アノード)がプラス側、短い脚(カソード)がマイナス側です。逆に接続すると点灯しません(壊れるとは限りませんが、正しい向きに接続し直してください)。

## 使用したコード

コードについて特別なことはしておらず、点滅の間隔(delay)を1,000ミリ秒(1秒)にした、という点だけ覚えています。以下は、その記憶をもとに再構成したサンプルコードです。ピン番号(2番)は説明のための一例であり、当時実際に使用した番号ではありません(未確認)。お使いの配線に合わせてピン番号を書き換えてください。

```cpp
// Lチカ(LED点滅)サンプルコード
// 対応ボード: Arduino Uno
// 使用ライブラリ: なし(Arduino標準関数のみ)
// 検証: 筆者の実体験をもとに再構成したコードです。ピン番号は一例のため、
//       お使いの配線に合わせて変更してから書き込んでください(未実機検証)。

const int LED_PIN = 2;  // LEDを接続したデジタルピン番号(2番。お使いの配線に合わせて変更してください)

void setup() {
  pinMode(LED_PIN, OUTPUT);  // LED_PINを出力モードに設定する
}

void loop() {
  digitalWrite(LED_PIN, HIGH); // LEDを点灯
  delay(1000);                 // 1000ミリ秒(1秒)待つ
  digitalWrite(LED_PIN, LOW);  // LEDを消灯
  delay(1000);                 // 1000ミリ秒(1秒)待つ
}
```

### コードの意味

- `pinMode(LED_PIN, OUTPUT)`: そのピンを「出力(OUTPUT)」として使う、とArduinoに教える命令です。ピンには入力(INPUT、センサーなどの信号を受け取る役割)と出力(OUTPUT、LEDなどに電気を送る役割)があり、使う前にどちらかを指定する必要があります。
- `digitalWrite(LED_PIN, HIGH)`: 指定したピンに電気を流す命令です。`HIGH`が「電気を流す(ON)」、`LOW`が「電気を止める(OFF)」を表します。
- `delay(1000)`: 指定したミリ秒(1000で1秒)の間、プログラムの動きをそこで止める命令です。この待ち時間があることで、点灯と消灯がゆっくり切り替わり、点滅に見えます。

## 失敗したこと・つまずいたこと

つまずいたのは、主に極性(LEDの向き)と、ピンの入出力設定(`pinMode`)の扱いでした。具体的にどんな症状が出たかまでは覚えていませんが(未確認)、一般的にはLEDの向きを間違えると点灯せず、`pinMode`で出力(OUTPUT)に設定していないピンを使おうとすると期待通りに動きません。

### どう解決したか

極性については、LEDそのものについて調べて解決しました。Arduino側の入出力設定については、Arduinoのデータシートなど公式の説明書をネットで調べて参照し、解決の手がかりにしました。

## 今なら初心者にこう説明する

自分自身はLチカそのものでは大きくつまずきませんでしたが、これから始める人には次の2点をしっかり伝えたいと思います。

- ピン配置の説明(どのピンが何の役割を持つか)は、配線前に必ずよく確認すること
- ブレッドボードの使い方(どの穴が電気的につながっているか)を理解してから配線すること

そして、LEDを壊したくない人は、電流制限用の抵抗を必ず使うことをおすすめします。あわせて、使用するLEDがどの程度の電流に耐えられるか(定格)を事前に調べておくと安心です。

## よくある質問

**Q. LEDに抵抗は絶対に必要ですか？**
A. 筆者自身は当時抵抗を使わずに配線しました。ただし、これは推奨される方法ではありません。抵抗を入れないとLEDや接続したピンに流れる電流を制限できず、LEDの早期劣化・焼損などにつながる可能性があります。これから取り組む方には、電流制限用の抵抗を入れることを強くおすすめします。

**Q. LEDの向き(極性)はどうやって見分ければいいですか？**
A. 一般的に、LEDの脚の長い方がアノード(+側)、短い方がカソード(-側)です。パッケージ根元の平らになっている部分がカソード側の目印になっている製品もあります。お手元のLEDのパッケージや説明書もあわせてご確認ください。

**Q. delay(1000)の数字を変えるとどうなりますか？**
A. delay()の中の数字はミリ秒(1000で1秒)を表します。数字を小さくすると点滅が速く、大きくすると点滅がゆっくりになります。値を変えて試してみると、動きの変化が分かりやすいと思います。

## まとめ

Lチカは、Arduinoで最初に取り組むのにちょうどいい課題です。一方で、今回あらためて振り返ると、電流制限用の抵抗を省略していた点は、初心者に安易にすすめられる方法ではないと感じました。これから取り組む方は、ピン配置とブレッドボードの使い方をよく確認したうえで、抵抗を使った安全な配線でLチカに挑戦してみてください。
